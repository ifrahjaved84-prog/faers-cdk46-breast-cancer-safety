# Comparative Safety Signals of CDK4/6 Inhibitors in Breast Cancer: Palbociclib, Ribociclib, Abemaciclib - A 10-Year FAERS Analysis (2015-2024)

Author:IFRAH 
ORCID: https://orcid.org/0009-0005-0033-4662
Focus:Breast Cancer Pharmacovigilance, CDK4/6 Inhibitor Safety, Real-World Evidence

## Background
CDK4/6 inhibitors (Palbociclib, Ribociclib, Abemaciclib) are standard for HR+/HER2- metastatic breast cancer, but real-world adverse drug reaction signals remain under-reported.

## Aim
To detect and compare ADR signals for Palbociclib, Ribociclib, and Abemaciclib using the FDA Adverse Event Reporting System (FAERS).

## Methods
- Data Source: openFDA FAERS 2015-2024
- Measures: Reporting Odds Ratio (ROR), Proportional Reporting Ratio (PRR), Information Component (IC), Empirical Bayes Geometric Mean (EBGM)
- Tools: Python (Pandas, OpenFDA API)

## Repository Structure
- `analysis.py` - Main analysis script (in progress)
- `data/` - Raw FAERS extracts
